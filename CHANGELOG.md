# Changelog

All notable changes to TTRPG Control Deck are recorded here.

## Unreleased

- Renamed the public product, repository, APK, screenshots, and setup package from GM Deck to TTRPG Control Deck.
- Preserved the existing Android package, deep-link scheme, storage keys, and backup format for compatibility.
- Refreshed tool views when navigating and isolated dice and saved-library state by campaign.
- Enlarged the header tools into touch-sized icons with an expanded active tool.
- Restored normal Android Home-button behavior by keeping the deck as a regular launcher app instead of a replacement Home app.

## 3.1.0 — 2026-08-31

- Added dedicated DM and Player interfaces with a two-tap role switcher.
- Added a per-campaign Player dashboard for HP, resources, modifiers, conditions, notes, and turn status.
- Added six editable Scene Director presets combining mode, page, ambience layers, and timer.
- Improved the persistent footer for the 960×480 target viewport.
- Added keyboard focus styling, descriptive labels, and long-label recovery titles.
- Added a wired-Ethernet Windows setup helper using a Private/LocalSubnet firewall rule.
- Added automated 960×480 browser validation and current interface screenshots.
