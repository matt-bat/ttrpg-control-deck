# TTRPG Control Deck 3.1.1

This is the first downloadable TTRPG Control Deck APK release.

## Highlights

- Refreshes each tool view from current state when navigating.
- Isolates dice history and saved-library content by campaign.
- Replaces small header controls with 44×44 touch targets and an expanded active tool.
- Keeps the app as a normal Android launcher application so Home returns to the tablet launcher.
- Preserves the existing `com.local.gmdeck` package and storage identifiers for compatible upgrades.

## Install or update

Download `TTRPG-Control-Deck.apk` and its `.sha256` file below, then follow the [complete installation guide](https://github.com/matt-bat/ttrpg-control-deck/blob/v3.1.1/docs/INSTALL.md).

This APK requires Android 6.0 or newer. Device unlocking or conversion is not included.
